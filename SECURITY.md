# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please do not open a public GitHub issue.

Instead, contact:
dylanspen@hotmail.com

## Scope

This repository is currently a source-available portfolio and research project and is not intended for production deployment.

Security reports are appreciated, but there are no guaranteed response times or support SLAs.

## Responsible Disclosure

Please provide:
- reproduction steps
- affected components
- potential impact
- suggested remediation if available
